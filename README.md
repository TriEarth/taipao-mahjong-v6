# 台炮 · 平阳麻将 V6

V6 是从 V5 完整复制出的独立版本，旧版本均未修改。规则以目录中的 `台数计算方式.txt` 为准。

## 启动

- 本机/同一 Wi-Fi：双击 `start.bat`，V6 使用端口 `3005`。
- 重复双击 `start.bat` 会复用已启动的麻将服务并打开游戏，不会中断已有房间。若3005端口由其他程序占用，会提示端口冲突，不会强行结束其他程序。
- 跨城市：双击 `start-public.bat`，把新生成的 `trycloudflare.com` 地址发给朋友。
- 单机测试：首页点击“单机测试”。
- 完全退出：在本机浏览器打开 `http://localhost:3005`，退出房间回到首页，再点“完全退出”。确认后会停止本机服务、断开所有房间、清除浏览器游戏记录；公网启动器也会停止隧道并退出，随后可重命名项目文件夹。公网或局域网玩家只能退出自己的会话，不能关闭服务器。

## 三人玩法

首页“玩法模式”可选择“四人经典”或“三人玩法”，再创建好友房或开始单机测试。加入已有房间时，以房主创建的模式为准。三人好友房三位即可开局，单机自动加入两名电脑。

- 沿用完整144张牌、十六张手牌和原有基本计台方式。
- 正常胡牌至少10台（自摸、接炮、抢杠、分张均检查）；胡牌总台数达到17台时整体翻倍一次，例如17→34、20→40。
- 摸齐一种财神3张、另一种财神1张必须立即推牌，由服务器自动结束本局；起手、普通摸牌、补花、杠后补牌和分张均检查。
- 3+1财神不能正常成牌时固定17×2＝34台，不叠加其他台型；正常成牌时，先计算全部正常胡牌台数，再加17台，最后整体翻倍一次。
- 三人按逆时针轮转，庄家为东，另两家为南、西。各家16张、无杠无补花时余牌为144−3×16−20−2＝74张；庄家多摸一张后73张。两张财神指示牌在预留20张之外另行扣除。每次正常摸牌减1，每个杠额外扣2；全桌补花（含白板）累计数向上凑偶数后扣除（1/2张扣2，3/4张扣4）。余牌包含最后三家分张；分张及补花均不得摸入预留牌。
- 结算页列出基础台数、额外17台及翻倍明细。房主核对的是最终结算台数，确认时不会再次翻倍。两位未胡牌者不足10台按0台，达到10台才计台；他们仅互算有效台数之差，不抵扣胡家应收。例如9台对12台，按0对12结算；10台对15台，支付5台差额。涉及庄家仍双倍。
- 四人经典模式继续使用原规则。

## 操作选择

- 他人出牌时，同一玩家可用的胡、碰、杠会一起显示，可直接选择碰或杠继续做牌。
- 点“过”放弃这张弃牌的所有响应，不再逐项询问。
- 选择碰或杠后仍优先等待其他玩家胡牌；其他人放弃后自动执行已选操作，无需重复点击。
- 抢杠时仅能胡或过；三人3+1财神继续遵守强制推牌规则。

## V6 核心变化

- 其他玩家的公开牌分成两个独立区域：碰牌、杠牌位于其左手边，花牌和白板位于其右手边，并与牌河及手牌背面错开。
- 东、南、西、北以庄家为东，沿实际出牌方向逆时针排列。
- 好友房人数不足时，房主可以逐个添加电脑玩家，补足四人后正常开局。
- 所有玩家摸牌、补花和出牌使用一次性流畅动画；状态轮询不会重复播放。
- 新版台数规则增加“无财神胡牌加5台”，红花与黑花分开按1/3/5/10台计算。

- 两张财神指示牌允许相同。相同时桌内只剩两张财神，一张计7台，摸齐两张可15台直接胡。
- 两种财神局：普通财神同种1/2/3张计2/5/8台；字牌、白板、花牌财神计3/7/11台。
- 3+1财神无法正常成牌时可15台直接胡；能正常成牌时在财神台数基础上加15台。
- 自动计算文档中的清牌、白板、花、财神、明暗杠、清混一色、对对胡、四风刻、杠上开花、自摸及抢杠胡。
- 胡牌后先进入“台数核对”阶段，不立即改变筹码。
- 房主可修改四位玩家台数，确认后才互相结算筹码。
- 非胡玩家之间按台数差额互付；胡家向每位玩家收取自己的完整胡牌台数；任一对关系涉及庄家时金额双倍。
- 新摸牌先停在最右侧；出牌后手牌才自动整理，财神归到最左侧。
- 保留逆时针摸打、单机模式、异地联机、分张和退出房间。

## 测试

```bash
node --test tests/*.test.js
```

测试覆盖新版财神与花牌台数、无财神加台、人工台数校正、筹码守恒、逆时针风位、好友房电脑补位、一次性动画事件、新摸牌右置、逆时针分张及随机开局。

## 部署

需要 Node.js 18+，启动命令 `node server.js`。公网部署端口读取环境变量 `PORT`。
